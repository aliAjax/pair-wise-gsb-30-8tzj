# 区域断供保供台

暴雨封路场景下的油品应急保供调度台，由「油品配送计划」扩展而来。

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- **油站登记**：库存、班均销量、保供等级、到站时段、所属片区。
- **罐车登记**：载重、可走片区、检修状态。
- **判定与排车**：撑不到下一班（库存 ÷ 班均销量 < 1 班）的站优先，按保供等级、可撑班次排序；罐车需片区可走、载重够缺口、到站时段不冲突才确认；排不下的进「留待派区」并写清缺口与原因。
- **解封**：释放未发车的原占位；已发车任务保留，只能登记接力车和原因。
- **留档**：登记、判定、排车、发车、解封、接力全部留痕，可导出 JSON。
- 数据保存在浏览器 localStorage，重开页面仍能看到排车与缺口。

## 目录

- `src/domain/` 数据模型与判定规则（纯函数：告急判定、缺口、罐车资格、时段冲突、自动排车）
- `src/stores/` 状态与动作（Pinia）
- `src/persistence/` localStorage 持久化
- `src/ledger/` 留档事件
- `src/components/` 页面（排车台 / 油站登记 / 罐车登记 / 留档）
