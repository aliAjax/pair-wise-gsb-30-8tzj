# 区域断供保供台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

暴雨封路期间，把配送计划扩成区域断供保供台：

- **油站登记**：库存、班均销量、保供等级、可接油到站时段；**罐车登记**：载重、可走片区、检修状态。
- **保供判定**：可撑班次（库存 ÷ 班均销量）< 1 即撑不到下一班，按保供等级 + 可撑班次优先排车；缺口 = 班均销量 × 2 − 库存。
- **确认条件**：罐车在役、片区可走、剩余载重够缺口、到站时段不冲突，四条同时满足才能确认。
- **待派区**：排不下的站写清缺口与原因，可手动改派罐车再次确认。
- **解封**：释放全部未发车占位并清空待派区；已发车任务保留，仅可登记接力车和原因。
- **持久化**：数据保存在浏览器 localStorage，重开仍能看排车与缺口。

代码分层（油站、判定、留档、页面分开）：

- `src/domain/`：油站/罐车模型（`types.ts`）、判定逻辑（`scheduler.ts`）、初始数据（`seed.ts`）
- `src/store/supplyStore.ts`：状态、留档与 localStorage 持久化
- `src/views/` + `src/components/`：判定台、油站登记、罐车登记、留档四个页面
